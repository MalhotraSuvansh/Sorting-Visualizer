# Sorting Algorithm Visualizer 📊

A web-based interactive tool built to visualize how different sorting algorithms work under the hood. 

**🔗 [Live Demo](https://malhotrasuvansh.github.io/Sorting-Visualizer/)**

## Features
* **5 Algorithms:** Visualizes Quick Sort, Merge Sort, Insertion Sort, Selection Sort, and Bubble Sort.
* **Real-Time Controls:** Adjust the array size and animation speed on the fly.
* **Complexity Stats:** Displays Best, Average, and Worst-case Time/Space complexity for each algorithm.
* **Step Tracking:** Tracks array accesses and swap operations in real-time.

## Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom styling, CSS Grid/Flexbox layouts, and UI animations.
* **Vanilla JavaScript:** Algorithm implementation, DOM manipulation, and asynchronous loop execution. Zero external libraries used.
